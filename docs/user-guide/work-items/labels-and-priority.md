# Labels and priority

Tag items and signal urgency.

**Audience:** All users

---

## Priority

Set **priority** in the work-item sidebar:

| Value                  | Typical use        |
| ---------------------- | ------------------ |
| **Lowest** / **Low**   | Nice-to-have       |
| **Medium**             | Default balance    |
| **High** / **Highest** | Urgent or blocking |

Priority appears in lists, board cards, and filters (**Shift+F** on Work Items).

---

## Labels

Labels are free-text tags stored on the item (e.g. `frontend`, `regression`).

1. Open a work item.
2. In the sidebar, find **Labels**.
3. Select the edit (pencil) control.
4. Add or remove labels and save.

Use labels to filter the registry and board. Search matches label text.

---

## Tips

- Keep label names short and consistent across the team.
- Combine priority + labels in **saved views** to bookmark common filters — see
  [Favorites and views](../navigation/favorites-and-views.md).
