# Comments and activity

Discuss work on the item and review what changed.

**Audience:** All users

---

## Discussion tab

1. Open a work item.
2. Select the **Discussion** tab.

Use the rich-text composer to add comments. You can:

- **@mention** project members (and the project owner). Workspace admins who are
  not members of the project are not suggested.
- **#mention** other work items in the **same project**
- Hover an `@` or `#` mention to preview a card (user profile or Kanban-style
  work item summary) after a short delay
- Use quick replies where shown (e.g. "Looks good!", "Need help?")
- Submit with **Ctrl/⌘+Enter**
- Press **M** to focus the composer from elsewhere on the page

React to a comment with the emoji chips under it, or open **Add reaction** to
pick from a small set (including 👍). Hover a chip to see who reacted. The time
under each comment is relative (for example, “2 minutes ago”); hover it for the
full date and time.

On the global **Comments** page, `#` suggestions appear after you pick a target
work item (scoped to that item's project).

Mentions and replies can generate [notifications](../notifications/dashboard-inbox.md)
for mentionable teammates.

While you keep the work-item page open, new and edited comments (and reactions)
from teammates (or another tab) appear in Discussion without refreshing the page.

---

## Activity tab

The **Activity** tab shows who changed what on the work item over time:

- Field updates (title, assignee, status, and similar)
- Workflow state transitions
- Attachments added or removed

Entries are sorted newest first. On the Activity tab bar, open the **layout**
menu (list icon) to switch how history is shown:

| Layout       | What you see                                               |
| ------------ | ---------------------------------------------------------- |
| **Cards**    | Bordered list rows (default)                               |
| **Timeline** | Vertical timeline with actor avatars and full descriptions |
| **Table**    | Dense When / Actor / Details table                         |

Your choice is remembered per work item in this browser.

Field and workflow changes made by teammates while you stay on the page show up
in Activity without a refresh.

Use the maximize icon on the right of the Discussion \| Activity \| Work Log
tab row to expand the whole section for long threads or history (same pattern
as the description editor).

---

## Work log tab

The **Work log** tab lists time logged against the item. Use the **+** on the
Work Log tab bar (or **+** next to **Time Tracking** in the sidebar) to open the
log-work dialog. Done or archived items may hide that control.

New work-log entries from teammates appear live while the page stays open.
