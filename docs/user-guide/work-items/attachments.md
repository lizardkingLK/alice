# Attachments

Upload and download files on a work item.

**Audience:** All users

---

## Upload a file

1. Open a work item (not **Done** — uploads are disabled on completed items).
2. Select **Attach** in the header or attachments section.
3. Choose a file from your device.
4. Wait for upload to finish — the file appears in the attachments list.

---

## Open or download

1. Select an attachment card in the list.
2. Alice opens a **signed preview or download URL** in the browser.

Links expire after a short time. If a link expired, use **Generate new link** on
the attachment card and try again.

---

## Limits and privacy

- Files are stored in private project storage — only users with access to the
  work item can fetch them.
- Delete attachments from the item while it is editable (not Done).
