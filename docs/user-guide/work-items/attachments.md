# Attachments

Upload and download files on a work item.

**Audience:** All users

---

## Upload a file

1. Open a work item (not **Done** — uploads are disabled on completed items).
2. Select **Attach** in the header or attachments section.
3. Drag and drop files, browse from your device, or paste with **Ctrl+V** /
   **Cmd+V** while the dialog is open.
4. Select **Upload**, then wait for upload to finish — the file appears in the
   attachments list.

---

## Open or download

1. Select an attachment card in the list.
2. Alice opens a viewer with a **signed preview** when it can (images, PDFs, and
   Markdown), plus **Download**. Use **Expand** in the viewer header for a larger
   preview. For Markdown, the first `#` heading is shown as the document title;
   later headings and bold text stay quieter so they do not compete with that
   title.

Links expire after a short time. If a link expired, use **Generate new link** /
**Refresh link** and try again.

---

## Limits and privacy

- Files are stored in private project storage — only users with access to the
  work item can fetch them.
- Delete attachments from the item while it is editable (not Done).
