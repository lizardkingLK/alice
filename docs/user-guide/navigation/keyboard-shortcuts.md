# Keyboard shortcuts

Speed up common actions without reaching for the mouse.

**Audience:** All users

---

## Global shortcuts

Shortcuts work on most dashboard pages. They **do not** fire while you're typing
in a field or while a dialog is open (unless noted).

| Shortcut     | Action                                                              |
| ------------ | ------------------------------------------------------------------- |
| **Ctrl/⌘+B** | Toggle sidebar open/closed                                          |
| **Ctrl/⌘+K** | Focus the page search box (lists and registries)                    |
| **Ctrl/⌘+K** | On **Docs** pages — open docs search (toggle while palette is open) |
| **Shift+F**  | Toggle work-items filter dialog (toggle again to close)             |
| **M**        | Focus the comment composer on a work-item **Discussion** tab        |

---

## Comment editor

While writing a comment on a work item:

| Shortcut         | Action         |
| ---------------- | -------------- |
| **Ctrl/⌘+Enter** | Submit comment |

---

## Tips

- Tooltips on search and filter controls mention shortcuts where available.
- There is no global shortcut cheatsheet overlay yet — bookmark this page or
  **Docs** for reference.
- Browser shortcuts (copy, paste, etc.) are unchanged.
