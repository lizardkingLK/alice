# Favorites and views

Star pages you open often and save filtered list URLs to reopen later.

**Audience:** All users

---

## Favorites (star)

1. Navigate to any dashboard page (e.g. Board, a work item, a project).
2. In the header, select the **star** next to the breadcrumb.

The star fills when the page is favorited. Select again to remove it.

Favorites store the **pathname only** (not query filters). They appear under
**Favorites** in the sidebar when you have at least one.

---

## Saved views (Layers)

1. Set up the page how you want it — filters, tabs, search terms in the URL.
2. Select the **Layers** icon in the header.
3. Enter a **title** (required) and optional description.
4. Save.

Saved views store **pathname + query string**, so filters are restored when you
open the view.

---

## Views workspace

Open **Views** in the sidebar (`/views`) to manage saved views:

| Tab                | Contents                     |
| ------------------ | ---------------------------- |
| **My views**       | Views you created            |
| **Shared with me** | Views others shared with you |
| **Archived**       | Views you archived           |

Row actions include **Open** (new tab), **Share**, **Archive** / **Restore**, and
**Delete** (for shared copies).

Sharing sends an in-app notification to recipients. Opening a shared view still
respects your normal role and project access.

---

## Favorites vs views

|             | Favorites     | Saved views                             |
| ----------- | ------------- | --------------------------------------- |
| **Stores**  | Path only     | Path + filters                          |
| **Sharing** | Personal      | Can share with teammates                |
| **Where**   | Sidebar group | **Views** page + optional notifications |
