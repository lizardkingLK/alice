# Forgot password

Reset your password when you can't sign in with email and password.

**Audience:** All users

---

## Steps

1. Open **Sign in**.
2. Select **Forgot password** (or go to `/forgot-password`).
3. Enter the **email** you use for Alice.
4. Submit the form.
5. Open the reset link in the email from Alice (check spam if needed).
6. On the reset page, enter a **new password** and confirm it.
7. Sign in with the new password.

---

## Notes

- The reset link is time-limited. Request a new one if it expires.
- You must still be on the **allowlist** and have an **active** account for
  sign-in to succeed after resetting.
- Google-only users who never set a password should use
  [Sign in with Google](./google-sign-in.md) or ask an admin for an invite
  email flow.
