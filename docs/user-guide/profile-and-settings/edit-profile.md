# Edit profile

Update your name, profile photo, and cover image.

**Audience:** All users

---

## Settings — General

1. Open **Settings** in the sidebar (`/settings`).
2. Stay on the **General** tab (or go from **Profile** → **Manage your account**).
3. Edit **name** and save.

---

## Profile photo

1. On **Settings → General**, use the avatar upload area (dropzone).
2. Choose an image, crop/zoom in the framing dialog, and confirm.
3. Alice stores the photo and updates your avatar across the app (comments,
   mentions, chat, assignee fields).

---

## Cover photo

1. Open **Profile** (`/profile`).
2. Use the cover upload control on the banner.
3. Crop and save — the cover appears on your profile page only.

---

## Other settings tabs

| Tab               | Examples                                                  |
| ----------------- | --------------------------------------------------------- |
| **Security**      | Password-related options; **Danger zone** self-deactivate |
| **Notifications** | In-app notification preferences (where configured)        |
| **Preferences**   | Browser UI prefs + personal Alice Chat model preference   |

**Integrations** appears for **managers and admins** — see
[Workspace integrations](./workspace-integrations.md).

### Preferences

Under **Settings → Preferences**:

- **Modern work item create** — compact create dialog vs full form
- **Auto-save project drafts** — when on, Add Project continuously saves your
  create wizard progress and resumes it automatically next time (no resume
  prompt or save-on-close dialog). When off, drafts stay manual.
- **Work item details** — banner color, title icon, and which sections/fields
  appear on every work-item page (same as **Configure** on a work item)
- **Alice Chat model** — prefer an organization chat model (synced to your
  account). Project AI binds still constrain the pool when you chat in a
  project. Choose **Workspace default** to clear the preference. New API keys
  are still managed only under [Workspace integrations](./workspace-integrations.md).

Browser-only toggles (create layout, drafts, work-item details) stay on this
device; the Alice Chat model preference syncs with your account.

---

## Self-deactivate

Under **Settings → Security**, the **Danger zone** lets you deactivate your own
account. You'll be signed out and cannot sign in again until an admin reactivates
you.
