# Deactivate users

Remove someone's ability to sign in while keeping their history in Alice.

**Audience:** Admin

---

## When to deactivate

Use deactivation when someone leaves the team or should no longer access the
workspace. Their past work items, comments, and assignments remain for audit and
continuity.

Deactivation is reversible — you can **reactivate** the account later if they
return.

---

## Steps

1. Go to **Users** as an **admin**.
2. Find the user (search by name or email).
3. Open the user actions menu.
4. Select **Deactivate** and confirm.

The user is signed out on next request and cannot sign in until reactivated.

---

## Deactivate vs allowlist

| Action                                  | Effect                                              |
| --------------------------------------- | --------------------------------------------------- |
| **Deactivate user**                     | Blocks this account even if allowlist still matches |
| **Remove / deactivate allowlist entry** | Blocks new sign-ups for that domain or email        |

For a leaver, usually **deactivate the user**. Adjust allowlist only if their
email should never be used again for self-registration.

---

## Reactivate

1. Find the deactivated user in **Users** (include inactive if filtered).
2. Choose **Reactivate**.

They can sign in again if the allowlist still allows their email.
