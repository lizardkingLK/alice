# User directory

Find colleagues and see who's in the workspace.

**Audience:** All users

---

## Admins: workspace user list

1. Sign in as an **admin**.
2. In the sidebar, open **Users**.

The **Users** tab lists everyone in the workspace. Search by name or email,
view roles, and activate or deactivate accounts (see
[Deactivate users](./deactivate-users.md)).

The **Users** page is admin-only in the app. Other roles don't open this
screen.

## Members and managers: finding people

If you're not an admin, you'll still see colleagues in context:

- Assignee and reporter fields on work items
- **Members** on a project you can access
- Mention and user pickers elsewhere in the app

To add someone new to Alice itself, ask an admin — don't expect a self-serve
directory page.

---

## What you can see

- **Name** and **email**
- **Role** (member, manager, admin)
- **Active** vs deactivated accounts (admins see status clearly)

Use search or filters when the list is long.

---

## What you can't do here (members)

Changing roles, the allowlist, invitations, and deactivation are **admin**
tasks. See [Users & access](./README.md) for admin pages.
